# 🌟 Dunia Bahagia Khaulah 3D (Keluarga & TK Karang Tengah 1 Atap)

Game web 3D interaktif yang dibuat dengan teknologi modern (React 18, Three.js, React Three Fiber, Vite, Tailwind CSS, Web Audio API), dirancang khusus untuk anak perempuan usia 6 tahun (**Khaulah**) dengan kontrol MacBook M2 yang mulus dan pengalaman bermain yang sangat personal, hangat, dan jauh melampaui Roblox biasa.

## ✨ Fitur Game Personal & Menghangatkan Hati

1. **👨‍👩‍👧‍👦 Keluarga Tercinta di Rumah Khaulah**:
   - **Abi (Ayah)**: Menyambut dengan senyuman hangat, bisa diajak tos (*high-five*) untuk menyemangati Khaulah!
   - **Ummi (Ibu)**: Menyiapkan *"Bekal Cinta Ummi"* (kue pelangi) yang memberikan efek lari super cepat (*speed boost*) dan taburan kilau bintang di langkah kaki Khaulah!
   - **Adek Khalid**: Adik balita periang yang berlari-lari membawa bola sepak dan mengajak Khaulah bermain bersama.
   - **Adek Faqih**: Adik bayi menggemaskan di kereta dorong yang menggoyangkan mainan kerincingan dan tertawa ceria (*cilukba*).

2. **🏫 TK Karang Tengah 1 Atap**:
   - **Gerbang Resmi**: Plang megah bertuliskan *"TK KARANG TENGAH 1 ATAP"* dengan pilar warna-warni ceria.
   - **Gedung Sekolah & Jam Dinding**: Ruang kelas pastel yang asri dengan menara jam di puncaknya.
   - **Tiang Bendera Merah Putih**: Bendera Indonesia yang berkibar dinamis tertiup angin sepoi-sepoi.
   - **Taman Bermain Interaktif (Bisa Dinaiki!)**:
     - **Perosotan (Slide)**: Khaulah bisa naik tangga lalu meluncur turun *"WUUUSSHH!"* dengan animasi lembut dan suara desiran angin.
     - **Ayunan (Swing)**: Khaulah bisa duduk berayun maju-mundur di ayunan yang bergerak dinamis.
     - **Jungkat-Jungkit & Kotak Pasir**: Tempat bermain santai bersama teman-teman.

3. **🌉 Lanskap Desa yang Asri & Jembatan Kayu**:
   - Teras rumah Khaulah dengan atap terakota, bangku taman kayu, dan jalan setapak bebatuan.
   - Sungai kecil dengan air berkilau jernih, bunga teratai, dan Bebek Kuki yang berenang santai.
   - Jembatan kayu melengkung yang menghubungkan rumah Khaulah menuju gerbang TK.

4. **🌈 Jalur Pelangi Ajaib ke Istana Bintang**:
   - Di balik sekolah TK terdapat gerbang portal pelangi menuju balok-balok angkasa, trampolin pantul super tinggi, pulau awan gula-gula, dan Istana Bintang Khaulah di puncak langit!
   - 25 bintang ajaib tersebar di halaman rumah, jembatan sungai, taman bermain TK, dan jalur pelangi.

5. **🎮 Kontrol MacBook M2 yang Ramah Anak**:
   - `W` / `A` / `S` / `D` atau Tombol Panah: Berjalan.
   - `Spasi`: Melompat (*dengan coyote-time & jump buffer*).
   - `E`: Bicara dengan keluarga (Abi, Ummi, Khalid, Faqih) atau Main perosotan & ayunan!
   - `Trackpad 2 Jari / Klik Kanan`: Putar kamera 360°.
   - `Scroll Trackpad`: Zoom in / zoom out kamera.
   - `Shift`: Mengaktifkan *Shift Lock*.
   - `Q`: Berjoget ceria 💃
   - `R`: Kembali ke checkpoint aman 🔄

## 🚀 Menjalankan Secara Lokal

Pastikan Node.js (versi 18+) sudah terpasang di komputer Anda:

```bash
# Clone repository
git clone https://github.com/sarrahman-me/game-khaulah.git
cd game-khaulah

# Pasang dependencies
npm install

# Jalankan dev server
npm run dev
```

Buka browser di `http://localhost:3000` untuk mulai bermain!

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **3D Graphics Engine**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) + [@react-three/drei](https://github.com/pmndrs/drei)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Audio**: Web Audio API sintetis (zero-lag, marimba sound generator)
- **Bundler**: [Vite](https://vitejs.dev/)
